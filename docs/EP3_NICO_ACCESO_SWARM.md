# Acceso externo Swarm

La ejecución 45328076266 confirmó salud interna de ocho servicios Java, pero agotó el tiempo de acceso al Gateway publicado. Se sustituye el routing mesh para Gateway y frontend por publicación host con una tarea global por nodo. El ALB de AWS distribuye a los dos nodos y la comunicación entre servicios conserva la red overlay privada. No se amplían reglas de seguridad ni se exponen bases de datos o servicios de negocio. Fuente de la configuración: https://docs.docker.com/engine/swarm/ingress/#bypass-the-routing-mesh . La prueba HTTP externa permanece obligatoria y no se sustituye por una llamada interna. Se agrega diagnóstico explícito del puerto si falla. Se integra además la corrección de rutas ALB e infraestructura de e7e99a3. El resultado debe comprobarse en CI antes de desplegar AWS.
